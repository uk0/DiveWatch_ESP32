🔄 DiveWatch BLE WiFi 配置

步骤:

  1. 设备上 长按 MODE+UP 3 秒 或开机时按 UP+DOWN 进 OTA 模式
  2. 下方点 "连接", 选择 "DiveWatch-OTA"
  3. 填 WiFi 名/密码, 点 "连接 WiFi"
  4. 设备屏幕显示 IP 后, 用 PC 推固件:
    arduino-cli upload -p <IP> --fqbn ... DiveWatch_v4
    或: espota.py -i <IP> -p 3232 -f DiveWatch_v4.ino.bin
