# DiveWatch 外壳设计

紧凑型 60×65×22mm 防水外壳，针对拓竹 PLA/PETG 打印优化。

## 设计参数

| 参数 | 值 | 说明 |
|---|---|---|
| 总尺寸 | 60 × 65 × 22 mm | 紧凑型, 类似 G-Shock 大小 |
| 上盖高 | 12 mm | 容纳 OLED + 主板 |
| 下底高 | 10 mm | 容纳电池 + TP4056 |
| 壁厚 | 2 mm | 强度 + 防水 |
| 外圆角 | 4 mm | 戴手腕舒适 |
| 表带耳间距 | 22 mm | 通用表带 |

## 内部空间分配

```
│  TP4056 (26×17×5)             │
└──────────────────────────────┘
```

## 关键特性

### 防水设计
- **上下盖间 O 圈密封**：1.8mm 截面 NBR O 圈, 周长约 240mm (淘宝定制)
- **MS5837 传感器孔**：⌀4mm 圆孔, 外圈 ⌀7mm O 圈槽密封传感器与外壳之间
- **USB-C 口**：使用硅胶塞 / 螺纹防水盖
- **按钮**：内部用硅胶按钮罩 (TPU 95A 打印) 或外贴硅胶薄膜
- **蜂鸣器透音孔**：⌀1.5mm 小孔 + 内贴 GORE-TEX 防水透音膜

### PLA 防水加强
PLA 不抗长期浸水, 需要表面处理:
1. **5 分钟环氧树脂**涂层 (推荐, 透明耐久)
2. **UV 透明胶水**全包 (简便)
3. **改用 PETG** 打印 (更耐水, 拓竹温度 235°C)

## 打印参数 (拓竹 P1S/X1)

| 参数 | PLA 推荐 | PETG 推荐 |
|---|---|---|
| 喷嘴温度 | 220°C | 240°C |
| 热床 | 65°C | 80°C |
| 层高 | 0.16mm | 0.20mm |
| 填充 | 30% gyroid | 40% gyroid |
| 壁数 | 4 圈 | 5 圈 |
| 支撑 | 螺丝沉头孔位需要 | 同 |
| 打印时间 | ~3 小时 (单半) | ~3.5 小时 |
| 表面后处理 | 环氧涂层 | 可省 |

## 装配清单

需要采购：
- M2 × 6mm 不锈钢圆头螺丝 × 4
- NBR O 圈 (定制 60×65 内圈周长 ~240mm, 截面 ⌀1.8mm)
- 22mm 通用表带 (硅胶/尼龙/钢带)
- 弹簧棒 22mm × 2 (装表带)
- ⌀7mm × 1.5mm 硅胶 O 圈 × 1 (MS5837 密封)
- USB-C 防水硅胶塞 (淘宝搜 "USB-C 防尘塞")
- GORE-TEX 透音膜 直径 5mm × 1 (淘宝 "防水透音膜")
- 硅胶按钮罩 × 3 (可选, 不加则灌环氧)

## 使用 OpenSCAD

### 安装
- macOS: `brew install openscad` 或下载 https://openscad.org
- Windows: 官网下载安装

### 操作
1. 打开 `divewatch_case.scad`
2. 顶部参数可调 (尺寸 / 间距等)
3. F5 预览, F6 渲染
4. 文件 → 导出 → STL
5. STL 拖入拓竹 Bambu Studio / OrcaSlicer
6. 切片, 上机打印

### 打印分两次
当前代码默认渲染**上盖**, 想打印下底:
```scad
// 注释这一行:
// top_cover();

// 取消注释:
bottom_case();
```

## 装配步骤

```
1. 打印两半外壳 (PLA, 约 6 小时)
2. 后处理: 表面打磨 + 环氧树脂涂层 (24h 干透)
3. 焊接所有电路 (按 wiring.md 接好)
4. MS5837 圆顶塞入下底中央孔, 涂硅胶密封外圈
5. 装电池到下底电池仓
6. 主板 + OLED 装上盖
7. 按钮压杆从上盖按钮孔插入
8. 放 O 圈到下底边缘 O 圈槽
9. 上盖盖上, 4 颗螺丝拧紧 (对角线顺序)
10. USB-C 口塞防水塞
11. 测试: 把表浸入水盆 30 秒, 取出擦干, 看内部是否进水
```

## 已知问题

- ⚠️ 当前设计**没有透镜窗口**, OLED 直接通过镂空可见 - 不防水! 必须额外加 PMMA 板用环氧密封到窗口内
- ⚠️ PLA 在 60°C 以上变软, 不要把表暴露在车内/直射阳光下
- ⚠️ 按钮压杆是 OpenSCAD 当前未画, 需要自己 3D 打印小柱体 (⌀6 × 3mm), 或直接外露 SMD 按钮
